TROUBLESHOOTING: PORT 5173 vs 5174
============================================================
React must be on port 5173 (matches CORS allowed_origins).
If Vite auto-picks 5174, something is using 5173:

netstat -ano | findstr :5173
→ Get the PID (e.g., 12345)
taskkill /PID 12345 /F
npm run dev -- --port 5173

After CORS changes:
php artisan config:clear
